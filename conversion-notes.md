# Foord International Fund - PDF to HTML Conversion Notes

## Template
`resources/views/funds/show-international.blade.php`

## Reference PDF
`reference-docs/Foord International Fund Class R at 2026-01-31.pdf`

## Status: Near pixel-perfect (16 iterations)

Both pages: 1123px each (exact A4 at 794px width)

## Remaining differences (inherent limitations)

### 1. Font rendering (web vs PDF)
Web browsers use different font rasterization/hinting than PDF renderers.
Avenir Next renders with slightly different character spacing and weight
on screen vs in print. This causes sub-pixel differences in text layout
throughout the document. **Cannot be resolved** - inherent to the medium.

### 2. Chart.js vs original charting tool
The PDF's portfolio performance chart was generated by a different tool
(likely Excel or a specialized finance charting tool). Chart.js produces
slightly different line smoothing, curve tension, grid lines, and tick
spacing. The chart data, colors, and annotations all match correctly.
**Cannot be resolved** without switching to the exact same charting tool.

### 3. Lipper Award icon
The PDF uses the official Refinitiv Lipper Fund Awards branded logo (a
stylized trophy). The template uses a simplified SVG shield approximation
since the branded asset is not available as a vector. **Requires** the
actual brand asset SVG/PNG to match exactly.

### 4. Feather icon
The footer feather icon is a simplified 2-tone SVG approximation of
Foord's branded feather asset. **Requires** the actual brand asset to
match exactly.

### 5. Header proportions (~4px difference)
The PDF header grey area appears to be ~78px tall. The template uses 74px
because increasing further would push page 1 beyond A4 height (1123px).
The header grey width is 218px vs PDF's estimated ~220px. These are
within 2% tolerance.
