## Reference PDF
`reference-docs/Foord Equity Fund Class A at 2026-01-31.pdf`

## Status: Complete (Iteration 4)

## Known Limitations

### 1. Low Carbon Badge
The reference PDF shows a "Morningstar® Low Carbon" badge at the bottom of the page 1 sidebar.
This badge is NOT stored in the fund data JSON — there is no `lowCarbon` key in the sidebar data.
No static image asset exists in the project for this badge.
**Decision**: Skip this element. It can be added later when the image asset is provided or the data structure is updated.

### 2. Font Substitution
The reference PDF uses "Avenir Next" as the primary font. This is a proprietary Apple font not available via Google Fonts.
**Decision**: Using "Lato" as the closest available Google Font, consistent with the existing templates. Lato has similar x-height and weight distribution.

### 3. Chart Rendering
Charts are rendered via Chart.js in the Puppeteer browser. The reference PDF's charts were likely generated by a different tool.
- Portfolio Performance chart: Using logarithmic Y-axis with end-of-line R-value annotations
- Monthly Performance chart: Using fixed Y-axis range (-10% to 10%) to match reference
- Exact pixel positions of chart elements may vary slightly from reference

### 4. Foord Logo
Using the external logo URL from the fund data (`https://foord.co.za/themes/custom/mirum/logo.png`).
The reference PDF uses a higher-resolution version of the same logo.
